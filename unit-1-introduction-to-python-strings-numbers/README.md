# Unit 1 – Introduction to Python, Strings & Numbers

## Overview

This unit introduces the foundations of Python programming and its role in solving real-world problems across a range of industries.

## Learning Objectives

By the end of this unit, I should be able to:

- Explain what Python is and describe three real-world applications of the language.
- Set up a working Python development environment.
- Write and run a basic Python script using `print()` and `input()`.
- Declare variables using `str`, `int`, `float`, and `bool`.
- Use `type()` to inspect the data type of a value.
