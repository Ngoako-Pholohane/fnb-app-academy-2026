# Unit 1 Practical Task

## Student Info Formatter

This task requires creating a Python script called `student_info.py` that collects personal information from the user and displays it in a formatted profile card.

## Requirements

- Collect first name
- Collect surname
- Collect age as an integer
- Collect a favourite number as a float
- Display a formatted greeting using an f-string
- Display the name in UPPERCASE using `.upper()`
- Display the name in Title Case using `.title()`
- Calculate age in months
- Round the favourite number to 2 decimal places
- Display the data type of each collected value using `type()`

## Skills Practised

- `input()`
- Variables
- Data types
- String methods
- Arithmetic
- `round()`
- `type()`
- f-strings
