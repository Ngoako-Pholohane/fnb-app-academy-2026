# FNB App Academy 2026

This repository documents my learning journey through the **2026 FNB App Academy**, in collaboration with the **University of Johannesburg's Johannesburg Business School (JBS)**.

The FNB App Academy is a free, online coding programme designed to take students with no previous coding experience through multi-level, hands-on modules covering programming, software development, and app creation.

## About Me

I am a medical student with a growing interest in technology, programming, data science, artificial intelligence, machine learning, and healthcare technology.

I am exploring how technology can be used to solve real-world problems, particularly in medicine and healthcare.

## Programme Curriculum

Throughout the FNB App Academy 2026, I will work through the following modules:

1. Introduction to Python
2. Manipulating Strings
3. Manipulating Numbers
4. Storage and Access
5. Selection of Tasks
6. Repeating Tasks
7. Design Thinking
8. Object-Oriented Programming
9. File Handling and Error Management
10. Kivy UI Basics
11. Multi-Screen App Development
12. APIs and Live Data
13. Build Sprint
14. Final App Showcase
